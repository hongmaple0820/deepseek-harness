# @deepseek-ai/dsh-client-ui-settings-user-data

[English](README.md) | 中文

## 概述

**设置 → 数据管理** 把一个 profile 带到另一台机器。该页按组件选择导出 ZIP 备份包，并以两步方式导入：选择文件只显示将要新增与替换的内容，只有点击应用按钮才会写入。个人设置文件与脱敏的偏好设置快照默认勾选；会话日志与凭据默认关闭。远端显示在文件操作下方：页面列出部署已配置的远端，也可以自行增删、测试连接，并推送或恢复同一种备份包。

## 使用本包

Web bundle 把本配套插件与 Host 的 `user-data-backup` 行一起挂载。用复选框选择组件后点击**下载备份包**，浏览器按 Host 给出的文件名保存。导入时点击**选择备份包**并选取 ZIP，先阅读计划变更：每个列出的组件都会说明将要新增与替换的路径，此时尚未写入磁盘。点击**应用导入**后才会写入，并报告保存被替换文件的备份目录。

Host 拒绝导入或备份包无法读取时，页面只显示一行失败信息而不显示计划。未选择任何组件时导出按钮被禁用，而不是下载一个空包。

**远端同步**列出每个远端，含类型、来源与其中已有的备份包。**刷新远端**重新读取列表；**推送备份**上传当前选择，并报告保存的文件名与 Host 清理掉的旧包数量；对某一行点击**恢复**会下载该备份包并打开同一份预览，因此来自另一台机器的包绝不会未经检查就写入。未配置远端时页面直接说明，而不是显示空列表。

**添加远端**会打开表单，填写协议与其地址字段；**保存远端**通过 Host 存储，保存后的行会报告每个密钥“已设置”，但从不显示其值。**测试**会列出该远端并报告条目数量，或报告远端返回的失败。**删除**只删本机添加的远端；来自配置的远端标记为**来自配置**，且不提供删除按钮。导入计划会在文件变更下方列出仍然脱敏的个人设置字段，便于在新机器上补齐。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

`transfer.ts` 负责路由地址、JSON 调用与已存备份包的下载，是唯一知晓线路细节的模块。`UserDataSection.tsx` 是只依赖 props 的纯组件：选择、远端列表、待应用计划、已应用结果与失败都存放在本地状态，下载动作由注入提供，保存时会丢掉留空的字段，让 Host 保留已存的密钥。`index.ts` 以自身语言命名空间注册 `settings.section` 页面，并注入点击锚点的下载动作。

</details>

## 已知限制与暂缓事项

<a id="known-limitations-and-deferred-work"></a>

- 本机添加的远端其密钥只能写入：已有密码或密钥显示为“已设置”，要更换只能重新输入一个值。
- 配置里已声明的远端 id 无法从页面再次添加。
- 页面在挂载时与手动刷新时读取远端列表；另一台机器之后推送的备份包需点击**刷新远端**才会出现。
- 上传较大的备份包时没有进度提示；推送按钮在 Host 应答前保持禁用。
- 计划按组件列出路径而不带单文件大小，因此勾选较大的会话备份时，应用前没有体积提示。
