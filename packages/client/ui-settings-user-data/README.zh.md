# @deepseek-ai/dsh-client-ui-settings-user-data

[English](README.md) | 中文

## 概述

**设置 → 数据管理** 把一个 profile 带到另一台机器。该页按组件选择导出 ZIP 备份包，并以两步方式导入：选择文件只显示将要新增与替换的内容，只有点击应用按钮才会写入。个人设置文件与脱敏的偏好设置快照默认勾选；会话日志与凭据默认关闭。远端显示在文件操作下方：页面列出部署已配置的远端，也可以自行增删、测试连接，并推送或恢复同一种备份包。

## 使用本包

Web bundle 把本配套插件与 Host 的 `user-data-backup` 行一起挂载。用复选框选择组件后点击**下载备份包**，浏览器按 Host 给出的文件名保存，按钮下方一行小字提示已交给浏览器下载，复选框区域下方还会标出当前选择带上了四类组件中的几类。导入时点击**选择备份包**并选取 ZIP，先阅读计划变更：未选择时卡片会说明还没有备份包，预览会标出读的是哪个文件或哪个远端的备份包，名字旁边就是备份包的大小，计划会统计将要新增、替换与跳过的文件数量，每个列出的组件都会说明它涉及哪些路径，此时尚未写入磁盘；预览打开后焦点在**关闭预览**上，关闭后回到**选择备份包**。预览可以关闭而不写入任何内容。点击**应用导入**后才会写入，并报告保存被替换文件的备份目录；若备份包取自远端，还会标出它从哪个远端恢复。

Host 拒绝导入或备份包无法读取时，页面只显示一行失败信息而不显示计划。未选择任何组件时导出按钮被禁用，而不是下载一个空包。

**远端同步**列出每个远端，含类型、来源与其中已有的备份包，Host 报出大小时会一并标出。**刷新远端**重新读取列表，卡片会标出这次读取的钟点，避免把早先的列表当成现状；卡片会写明当前推送会带上哪些组件；**推送备份**上传该选择，所在行会先显示上传进行中，Host 应答后再在这张行上报出它清理掉的旧包数量（没有清理时不显示）——刚存下的备份包本身已出现在该行的列表中；若写入已经生效但列表读不回来，卡片会保留这份回执，只说明列表停留在旧状态；读取失败时，失败信息出现在它没能替换的那些行上方，旁边就是**重试**，而更早读到的那批行会留在原处，标题区的钟点仍标出那是哪一次的读取；对某一行点击**恢复**时会先显示正在读取哪个备份包，下载后打开同一份预览并在标题旁标出它来自哪个远端与哪个备份包，因此来自另一台机器的包绝不会未经检查就写入；应用这份预览后，提示写成恢复而不是导入，并再次说明来源。连接测试的结论旁带有测试发生时的钟点，避免把过期的条目数当成现状。未配置远端时页面直接说明，而不是显示空列表，且这条提示自带**添加远端**入口，添加第一个远端不必去头部找按钮。

**添加远端**会打开表单填写协议与其地址字段，表单打开期间该按钮不再出现，因此填了一半的草稿不会被悄悄丢掉；没有协议、无法解析的地址会在字段下方标出，并让**保存远端**等到地址可用。同一时刻只允许一个远端调用，被拒绝的调用就在引发它的表单里报告，浏览器连不上 Host、以及 Host 在时限内没等到远端，都与拒绝回答分开说明；删除确认会接过焦点，取消后再还给原来的按钮。**保存远端**通过 Host 存储连接，保存后的行会报告每个密钥“已设置”，但从不显示其值。**测试**会列出该远端并报告条目数量，或报告远端返回的失败。**全部测试**按行的顺序对每个远端运行同一测试，一次扫过就在每一行留下结论；单个测试还在跑时该控件会等待。**删除**会先确认并说明它做了什么：只忘记本机保存的连接，远端上的备份包仍在；来自配置的远端标记为**来自配置**，且不提供删除按钮。导入计划会在文件变更下方列出仍然脱敏的个人设置字段，便于在新机器上补齐。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

`transfer.ts` 负责路由地址、JSON 调用与已存备份包的下载，是唯一知晓线路细节的模块。`UserDataSection.tsx` 是只依赖 props 的纯组件：选择、远端列表、待应用计划、已应用结果与失败都存放在本地状态，下载动作由注入提供，保存时会丢掉留空的字段，让 Host 保留已存的密钥。`index.ts` 以自身语言命名空间注册 `settings.section` 页面，并注入点击锚点的下载动作。

</details>

## 已知限制与暂缓事项

<a id="known-limitations-and-deferred-work"></a>

- 本机添加的远端其密钥只能写入：已有密码或密钥显示为“已设置”，要更换只能重新输入一个值。
- 配置里已声明的远端 id 无法从页面再次添加。
- 页面在打开时与点击**刷新远端**时读取远端列表；另一台机器之后推送的备份包要等下次刷新才会出现。
- 上传较大的备份包时没有进度提示；推送按钮在 Host 应答前保持禁用。
- 计划按组件列出路径而不带单文件大小，因此看不出哪个组件占了主要体积；备份包自身的大小就标在名字旁边，应用前一眼可见。
